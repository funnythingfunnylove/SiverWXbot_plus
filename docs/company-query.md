# 后台企业查询（天眼查）

后台左侧新增「企业查询」。功能随原有 `web_server.py` 运行，无需单独启动 MCP 服务、安装 Node.js 或开放额外端口。企业数据通过 Chrome 已登录的天眼查页面获取，不需要导出 Cookie。

当前版本支持企业关键词搜索第一页（最多 20 个候选）和企业工商详情。查老板、关联人物、自动翻页尚未开放。网页提取器依赖天眼查实际页面结构；本版协议及管理接口已有自动化测试，但真实网站扩展查询仍须在部署环境验收。

## 源码部署

在原有 Windows 环境停止机器人，拉取代码并重启：

```powershell
git pull --ff-only origin main
python -m pip install -r requirements.txt
python web_server.py
```

访问原来的后台地址并登录，打开「企业查询」。不需要配置 MCP 工具页。本功能是后台管理查询入口，不会自动向微信用户开放查询权限。

若使用打包 exe，必须重新打包并包含 `company_routes.py`、`integrations/tianyancha_mcp/bridge.py`，以及资源目录 `integrations/tianyancha_mcp/extension`、更新的 `templates`；仅更新模板或复制 Python 文件不能更新旧 exe。源码部署会自动包含扩展下载所需文件。

## 浏览器配对

1. 在「企业查询」下载 Chrome 扩展并解压。
2. Chrome 打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，选中解压后的 `tianyancha-bridge` 目录（包含 manifest.json）。
3. 在这个 Chrome 中登录天眼查。
4. 后台点击“生成新的配对令牌”，复制页面显示的桥接地址和令牌。
5. 点击扩展图标 → “打开天眼查 MCP 桥接”，填写地址和令牌，点击连接；Chrome 会请求访问指定后台域名的权限。
6. 保留桥接页面，返回后台点击“刷新连接状态”，显示已连接后查询企业。

Chrome 可以在后台服务器本机，也可以在另一台电脑。跨电脑连接需要可访问的 HTTPS 后台地址；本机地址可用 HTTP，例如 `http://127.0.0.1:10001/api/company/bridge`（端口以后台实际显示为准）。不要把另一台电脑的 `127.0.0.1` 当作服务器地址。

如果通过代理前缀访问后台，复制页面生成的完整地址。代理需要原样转发 `Authorization` 请求头和 `/api/company/bridge/*` 请求；查询接口的代理超时应至少 60 秒。若远程平台强制浏览器 Cookie 登录且拦截扩展请求，需要为桥接提供正确的 HTTPS 转发入口；本版不对未知远程平台兼容性作保证。

## 查询与状态

输入关键词后，先显示候选企业，再点击“查看工商信息”。搜索结果可能包含关联企业，请对照企业全名和统一社会信用代码。详情保留源页面字段原文、采集时间和页面更新日期；缺失项显示“未取得”，不推断为零或不存在。

每个后台进程只有一个配对账号、一个查询任务。并发查询会提示稍后重试；查询最长等待约 45 秒。浏览器未连接、账号需要登录、人工验证、访问频繁、页面结构不兼容分别返回提示，不会自动破解验证或反复重试。

配对令牌只保存在后台进程内存与当前页面，不进入项目配置或代码。后台重启、生成新令牌、点击撤销连接都会使旧令牌失效。管理员可以通过撤销连接停止后续查询。扩展页面关闭或 Chrome 休眠后需要重新连接。不要分享配对令牌。

后台管理接口使用原有登录校验，修改与查询接口要求专用请求头。扩展仅通过配对令牌访问领取任务和提交结果两个接口，无后台管理权限。扩展申请的可选 HTTP(S) 权限用于用户填写的后台域名；实际连接时仅请求该域名的权限。天眼查页面脚本只访问固定站点和企业搜索/详情路径。

当前设计适用于项目现有的单进程、线程式 Flask 服务。不要部署多 worker，否则配对状态和任务不共享；未来多进程部署需把任务及会话存储迁移到共享服务。

## 上线验收

- 未登录后台不能查询、下载扩展或生成令牌。
- 扩展连接后，搜索“广州谢诺投资集团有限公司”，检查候选是否包含企业 ID `3408099107`。
- 打开企业详情，对照天眼查实际页面核对名称、信用代码、资本、地址。
- 刷新网页、注销天眼查、遇到验证页时，确认错误提示符合实际情况。
- 撤销配对或重启后台后，旧扩展应不能继续领取任务。

独立 MCP 用法仍保留在 `integrations/tianyancha_mcp/README.md`，与后台入口独立；后台部署不需要启动它。
