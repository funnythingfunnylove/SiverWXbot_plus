添加 MCP 服务

通过本机 Chrome 登录网页读取数据，无需天眼 AI 密钥。先启动独立网页 MCP 服务并连接浏览器扩展，默认地址 http://127.0.0.1:18766/mcp。测试连接只发现工具，不代表网页已登录。安装步骤见 docs/company-query.md。自定义端口可用“添加 MCP 服务”。

填写 MCP 端点，不是普通网页或 REST API。可连接这台 Windows 电脑能访问的内网地址；本版不支持 stdio、旧 SSE 或交互式 OAuth 登录。
保存在本机配置中，不发送给模型，也不在列表中回显。

允许调用的工具

普通服务测试只获取工具列表；项目管理用户测试还会调用只读 weekly_identity 核验人员与工具权限。勾选即授权机器人在全部私聊及下方已授权群聊中自动调用；写入、删除和通知类工具也会真实执行，请只开放你允许的操作。“只读”标记来自服务声明，仍需核对工具用途。

全部私聊均可使用已启用服务的所选工具，无需设置联系人白名单。旧名单不再限制访问。仍需开启监听和 AI 回复。

添加授权群后，群内所有成员 @ 机器人即可使用所选工具，无需添加人员名单。未 @ 的群消息不调用 MCP；仍需开启该群的监听与 AI 回复。
