Skill 管理

启用的 Skill 在下一次 OpenAI 兼容助手对话中生效（含图片对话），由助手按问题匹配使用。Skill 是业务指引，不会授予 MCP 权限或执行本机命令；不作用于 Dify / Coze / DusAPI。

支持 Markdown 文件或 ZIP 技能包（最大 10 MiB）。ZIP 可包含技能文件夹，需有且只有一个 SKILL.md；保存时保留完整文件夹结构、脚本及附件。


    
    
技能以独立文件夹保存，编辑正文会保留其他文件。启用后加载正文及限额内的文本附件，脚本与二进制资源会保留，但不会自动执行或解析；启用前请检查内容，不要写入 API 密钥。最多保存 50 个，启用内容总计最多 80000 字。
